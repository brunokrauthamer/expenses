# Expenses

Aplicação simples para registrar despesas pessoais. Os dados ficam na memória do navegador durante a sessão e são apagados ao recarregar a página.

## Requisitos

- Node.js 20.19+ ou 22.12+
- pnpm

## Executar localmente

1. Instale as dependências: `pnpm install`
2. Inicie o servidor de desenvolvimento: `pnpm dev`
3. Abra no navegador o endereço mostrado pelo Vite (normalmente `http://localhost:5173`).

Para gerar uma versão de produção, execute `pnpm build`. Os arquivos gerados ficam em `dist/`.
